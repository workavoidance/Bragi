# Skrivi v0.2.0 alpha 3

This alpha improves automatic language detection and dark-mode readability,
and adds a direct way to send feedback from Skrivi.

## Install or update

Download and run `Skrivi-v0.2.0-alpha.3-windows-x64-setup.exe` below. You can
install it over an earlier alpha. Existing settings and downloaded speech
models are kept.

The installer needs no administrator permission and adds Skrivi to the Start
menu and Windows Installed apps.

This alpha is not code-signed. Windows SmartScreen may therefore show a warning.
If you trust this open-source project, choose **More info**, then **Run anyway**.

## What changed

- Automatic language detection now considers only Norwegian and English,
  reducing unrelated-language guesses. The language choices are now Automatic,
  Norwegian, and English; an existing Multilingual setting moves to Automatic.
- Status, privacy, and model panels remain readable when Windows uses dark mode
  and translucent palette colours.
- The floating dictation indicator follows the active Windows theme.
- Skrivi's orange application mark remains visible in dark mode.
- The tray menu has a **Give feedback** action that opens Skrivi's feedback
  page.
- The release workflow can now also create an unsigned MSIX package for a
  Microsoft Store submission. Store availability remains subject to Microsoft's
  certification process.

## Alpha limitations

- Windows 11 on x64 processors is the only supported platform in this release.
- The binaries are not code-signed and may trigger SmartScreen.
- Accessibility, repeated-cycle, offline, and broader hardware testing are not
  yet complete.
- Skrivi is not presented as formally approved for school deployment. Schools
  and municipalities must conduct their own review.
- Very short phrases may still be assigned to the wrong one of the two
  automatic languages, and punctuation may be imperfect.

Please report problems using **Give feedback** in Skrivi's tray menu or through
[GitHub Issues](https://github.com/workavoidance/Skrivi/issues).
