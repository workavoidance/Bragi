# Skrivi v0.2.0 alpha 4

This alpha adds laptop-friendly push-to-talk shortcuts and enables automatic
startup in the Microsoft Store edition.

## Install or update

Download and run `Skrivi-v0.2.0-alpha.4-windows-x64-setup.exe` below. You can
install it over an earlier website edition. Existing settings and downloaded
speech models are kept.

The installer needs no administrator permission and adds Skrivi to the Start
menu and Windows Installed apps.

This direct installer is not code-signed. Windows SmartScreen may therefore
show a warning. If you trust this open-source project, choose **More info**,
then **Run anyway**. Microsoft signs the separate Store edition after
certification.

## What changed

- Add **Left Ctrl + Windows** as the recommended laptop push-to-talk shortcut
  and **Left Ctrl + Left Alt** as a fallback while keeping **Right Ctrl** as the
  default.
- Delay two-key shortcut activation briefly so ordinary Windows shortcuts with
  a third key continue to work normally.
- Show the selected shortcut in Skrivi's ready status.
- Support opt-in automatic startup in the Microsoft Store edition using
  Windows' packaged startup-task API.
- Respect startup choices made by the user or an organisation in Windows
  Settings and keep Skrivi's checkbox synchronized with the effective state.

## Alpha limitations

- Windows 11 on x64 processors is the only supported platform in this release.
- The direct-download binaries are not code-signed and may trigger SmartScreen.
- Accessibility, repeated-cycle, offline, and broader hardware testing are not
  yet complete.
- Skrivi is not presented as formally approved for school deployment. Schools
  and municipalities must conduct their own review.
- Very short phrases may still be assigned to the wrong one of the two
  automatic languages, and punctuation may be imperfect.

Please report problems using **Give feedback** in Skrivi's tray menu or through
[GitHub Issues](https://github.com/workavoidance/Skrivi/issues).
