# Skrivi v0.2.0 alpha 1

This is the first installer-backed alpha release of Skrivi, a private local
push-to-talk dictation application for Windows 11.

## Install

Download and run `Skrivi-v0.2.0-alpha.1-windows-x64-setup.exe` below. The
installer needs no administrator permission and adds Skrivi to the Start menu
and Windows Installed apps.

This alpha is not code-signed. Windows SmartScreen may therefore show a warning.
If you trust this open-source project, choose **More info**, then **Run anyway**.

The first launch downloads and verifies the recommended multilingual Small
speech model, approximately 486 MB. Once installed, normal dictation runs
locally without sending audio or transcripts to Skrivi or a cloud service.

## Included

- English and Norwegian Bokmål interfaces.
- Automatic, English, Norwegian, and multilingual speech modes.
- Right Ctrl or F6 through F12 push-to-talk keys.
- Windows microphone selection and disconnected-device recovery.
- Verified local Tiny, Base, Small, and Medium speech models.
- Download, verification, switching, import, removal, progress, and cancellation.
- Per-user installer, normal uninstall, optional desktop shortcut, and optional
  automatic startup.
- Portable Windows ZIP for advanced users.

## Alpha limitations

- Windows 11 on x64 processors is the only supported platform in this release.
- The binaries are not code-signed and may trigger SmartScreen.
- Accessibility, repeated-cycle, offline, and broader hardware testing are not
  yet complete.
- Skrivi is not presented as formally approved for school deployment. Schools
  and municipalities must conduct their own review.
- Whisper may occasionally choose the wrong language for very short phrases or
  produce imperfect punctuation.

The installer has passed automated Windows CI and manual installation,
dictation, settings-preservation, automatic-startup, and uninstall checks on one
Windows 11 computer. Please report problems through
[GitHub Issues](https://github.com/workavoidance/Skrivi/issues).
