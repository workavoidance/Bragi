# Skrivi v0.2.0 alpha 2

This alpha gives Skrivi's settings a calmer, clearer interface for early test
users. Dictation behaviour and local privacy protections remain unchanged.

## Install or update

Download and run `Skrivi-v0.2.0-alpha.2-windows-x64-setup.exe` below. You can
install it over alpha 1. Existing settings and downloaded speech models are
kept, so the recommended Small model does not need to be downloaded again.

The installer needs no administrator permission and adds Skrivi to the Start
menu and Windows Installed apps.

This alpha is not code-signed. Windows SmartScreen may therefore show a warning.
If you trust this open-source project, choose **More info**, then **Run anyway**.

## What changed

- Clearer status, dictation, and application sections.
- A compact window suitable for laptop displays, with Save and Cancel always
  available.
- Helpful explanations that change with the selected dictation language.
- Simpler model management that shows only relevant actions.
- A fuller privacy summary, including what Skrivi does not store and what the
  receiving application may store or sync.
- A more useful About page with direct links to the website, source code, and
  third-party licences.
- Stronger keyboard focus, disabled states, control outlines, high-contrast
  behaviour, and dark-palette support.
- Complete English and Norwegian Bokmål wording for the redesigned interface.

## Alpha limitations

- Windows 11 on x64 processors is the only supported platform in this release.
- The binaries are not code-signed and may trigger SmartScreen.
- Accessibility, repeated-cycle, offline, and broader hardware testing are not
  yet complete.
- Skrivi is not presented as formally approved for school deployment. Schools
  and municipalities must conduct their own review.
- Whisper may occasionally choose the wrong language for very short phrases or
  produce imperfect punctuation.

The application, installer, and redesigned settings passed automated Windows
CI. The complete interface was also reviewed manually in English and Norwegian
Bokmål. Please report problems through
[GitHub Issues](https://github.com/workavoidance/Skrivi/issues).
