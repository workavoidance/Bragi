# Security policy

**Language:** [Norsk](SECURITY_NB.md) | English

## Supported versions

Skrivi is pre-1.0 software. Security fixes are applied to the latest
released version.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting feature rather than a
public issue. Include reproduction steps, affected versions, and the expected
impact where possible.

Do not include real recordings or transcripts in a report. Use synthetic test
content if an example is required.
